# Завдання №7 - Метод Монте-Карло. Кидання двох кубиків

У даному завданні було змодельовано кидання двох гральних кубиків
за допомогою методу Монте-Карло.

## Опис роботи
Було виконано велику кількість кидків двох кубиків.
Для кожного кидка обчислюеться сума чисел, які випали.
Після цього підраховуеться кількість появ кожної суми
та обчислюеться ймовірність її появи.

## Порівняння результатів
Отримані ймовірності були порівняні з аналітичними значеннями,
які відомі для двох гральних кубиків.
Результати методу Монте-Карло є дуже близькими до теоретичних значень.

## Висновок
Метод Монте-Карло дозволяє наближено оцінити ймовірності випадкових подій.
Чим більша кількість симуляцій, тим точнішим буде фінальний результат.
